# ZundaConverter

日本語テキストをずんだもん風の口調に変換する macOS メニューバーアプリです。

「〜です」→「〜なのだ」、「私」→「ボク」のように、文末表現と一人称を自動で変換します。Slack やメール、チャットなどで利用できます。

## インストール

1. [GitHub Releases](https://github.com/beryu/zunda-converter-macos/releases/latest) から最新の `.dmg` ファイルをダウンロード
2. `.dmg` を開き、`ZundaConverter.app` を Applications フォルダにドラッグ＆ドロップ
3. アプリを起動するとメニューバーに 💬 アイコンが表示されます

## 動作環境

- macOS 26 以降
- AI モードを利用する場合は Apple Intelligence が有効であること

## 使い方

### サービスメニューから変換

1. 任意のアプリでテキストを選択
2. 右クリック → **サービス** → **「ずんだもんに変換」** を選択
3. 選択テキストが変換結果に置き換わります

### グローバルショートカットで変換

1. メニューバーアイコンから **設定** を開く
2. 「ショートカット」セクションでお好みのキーの組み合わせを登録
3. 任意のアプリでテキストを選択し、登録したショートカットを押す
4. 選択テキストがコピー → 変換 → ペーストされます

> **Note:** ショートカット機能を使うにはアクセシビリティ権限の許可が必要です。設定画面内の案内に従って「システム設定 → プライバシーとセキュリティ → アクセシビリティ」から許可してください。

### 変換モードの切り替え

メニューバーアイコンのメニューから **変換モード** を選択し、以下の2つのモードを切り替えられます。

| モード | 概要 | 特徴 |
|--------|------|------|
| **ルールベース** | 正規表現によるパターンマッチング | 高速・即時変換。機械的だが安定 |
| **AI モード（実験的）** | Apple Intelligence による変換 | 自然な口調変換。文脈を考慮した柔軟な変換が可能 |

### プレビュー機能

設定画面の「プレビュー」タブで、変換前後のテキストを確認できます。

## AI 機能のアーキテクチャ

AI モードは Apple の **Foundation Models** フレームワーク（`FoundationModels`）を使用しています。

### 処理フロー

```
ユーザーのテキスト入力
        │
        ▼
┌─────────────────────┐
│   TextConversion    │  変換モードに応じてディスパッチ
│      Engine         │
└────────┬────────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌────────┐ ┌────────────┐
│ルール  │ │  LLM       │
│ベース  │ │ Converter  │
│変換    │ │            │
└────────┘ └─────┬──────┘
                 │
                 ▼
        ┌────────────────┐
        │ Foundation     │
        │ Models         │
        │ (on-device)    │
        └────────────────┘
```

### オンデバイス処理

AI モードで使用される Foundation Models フレームワークは、macOS に組み込まれた **オンデバイス言語モデル**（`SystemLanguageModel`）を利用します。

- テキストの変換処理は **すべてデバイス上で完結** します
- 変換対象のテキストは **外部サーバーやクラウドに一切送信されません**
- ネットワーク通信は発生せず、オフライン環境でも動作します
- Apple の Foundation Models フレームワークの仕様として、推論はデバイスのローカルプロセッサ（Apple Silicon の Neural Engine）上で実行されます

> Foundation Models フレームワークの詳細は [Apple 公式ドキュメント](https://developer.apple.com/documentation/foundationmodels) を参照してください。

### ルールベース変換

ルールベースモードでは、正規表現によるパターンマッチングで文末表現と一人称を変換します。こちらも完全にローカルで動作し、外部通信は行いません。

### フォールバック機構

AI モードで以下のケースが発生した場合、自動的にルールベース変換にフォールバックします。

- Apple Intelligence が無効または未対応のデバイス
- モデルの安全フィルターによりリクエストが拒否された場合
- レスポンスの JSON パースに失敗した場合
